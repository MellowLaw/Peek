4. OPT-IN FEATURES & WINDOWS PERMISSIONS
Sensitive capabilities stay disabled or dormant until you turn them on or
explicitly trigger them:
- Camera (Cam tab): Webcam access turns on only when toggled on by you.
  Snapshots save locally to Pictures\Peek.
- Screen Capture & Recording: Captures occur only on your action. Screen
  recording uses your locally installed FFmpeg binary when present.
- Clipboard & Notification History: Disabled by default; stored locally
  only when enabled in Settings.
- Phone <-> Desktop QR Transfer: Runs an ephemeral token-protected HTTP
  server strictly on your local Wi-Fi/LAN for the active transfer session.
  Allowing Peek through Windows Defender Firewall prompts UAC once.
- Local Event API: Optional 127.0.0.1 loopback-only server secured with
  a per-device Bearer token.
- AI Usage Monitor: Reads local provider quota logs read-only; Peek
  never reads prompts, secrets, or source repositories.

5. NETWORK CONNECTIONS & UPDATES
Peek connects to external servers only when:
- Checking for signed Peek updates via GitHub Releases (startup/manual);
- Fetching synced lyrics from a user-configured local Lyrical instance
  or album metadata fallback when music playback is active.

6. WINDOWS SMARTSCREEN & UNINSTALL
Open-source releases may trigger Windows Defender SmartScreen on first
launch because they are not signed by a commercial Authenticode CA. You
may uninstall Peek anytime via Windows Settings -> Installed apps; remove
%APPDATA%\com.mellowlaw.peek to clear saved local app data.
